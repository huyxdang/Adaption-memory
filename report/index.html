Overnight evaluation · 2026

Better memory starts at write time. Does it pay?

Full-history inference is accurate but repeatedly pays to reread every prior turn. We tested whether an append-only write-time memory can retain enough signal to lower that read cost—without changing the Luna answerer.

Limitations

  • Signal subsamples are decision aids, not confidence-bounded full benchmark scores.
  • One answer model and one judge model were used, both Luna with effort none.
  • The strict key-string recall proxy undercounts paraphrased but useful memories.
  • Full-history baseline latency was not stored, so no latency reduction is claimed.
  • Benchmark-scale conversations are not the same as relationship-scale, continuously evolving memory.
  • SFT provenance remains development-split only until verified official train splits are provided.
