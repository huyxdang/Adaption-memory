🧸 ELI5 project story

We built a notebook for a forgetful robot.

Then we gave the robot small, medium, and giant exams to see whether its memory actually worked.

💡

The big idea: do not wait until question time to search a giant chat pile. Make clean notes while the chat is happening.

What happened, from the beginning

One small working layer at a time.

1🗺️

We opened the box

The repo already knew how to read and score three memory exams. But its clever write-time memory was still mostly a plan. We mapped the code and found the missing pieces.

CODE SCAN
2🗂️

We built the notebook

Each chat session now makes story notes and exact fact cards. New facts can replace old facts without deleting history. A simple finder picks the useful notes for each question.

ADAPTIVE MEMORY
3🧠

We needed a robot brain

Ollama became the local engine. Qwen was the brain inside it. The tiny 0.6B model was good for checking pipes, but not dependable enough for the real memory exam.

OLLAMA + QWEN
4🚧

The company network said “no”

Trusted model sites were blocked. Turning off TLS did not solve the real policy block. We prepared safe allowlist/offline routes, then the hotspot let Ollama resume and finish the 1.7B download.

NETWORK DETOUR
5🔧

The exams found real bugs

The stronger models exposed date mistakes, stale facts, loose matching, token-limit problems, and scorer edge cases. We fixed each one and added a test so it could not quietly return.

1.7B → 4B
6☁️

Luna gave us a cloud check

GPT-5.6 Luna answered the small exam with medium reasoning; another Luna pass judged with high reasoning. The key lived only in a temporary process and was never saved in the repo.

HOSTED BASELINE
7📏

The first mini exam was too tiny

It touched every skill, but one answer could swing a whole category. You challenged that. So we kept it as “smoke” and built a larger, distribution-aware “signal” exam.

22 → 90 QUESTIONS
8🔒

We locked the measuring tape

Every run now records which data, model, settings, and endpoint it used. Smoke, signal, and full results cannot be accidentally mixed. Source files also have fingerprints.

PROVENANCE + 44 TESTS

The different “brains” we discussed

More size usually means better judgment—but also more waiting.

🐣

Qwen 0.6B

Very fast. Good for “does the pipe work?” Not trusted for benchmark quality.

🐤

Qwen 1.7B

Daily local helper. Fast enough to iterate and clean enough to judge simple labels.

🦉

Qwen 4B

Stronger local answerer. Used for the more serious pre-final local check.

🚀

GPT-5.6 Luna

Cloud speed + quality. Used for the measured hosted smoke baseline.

The three exams

“Benchmark” is just a grown-up word for a repeatable test.

🧵

LongMemEval

Can the robot find an old fact hidden among many chat sessions—including updates and “not enough information” questions?

🗓️

LoCoMo

Can it remember people, dates, details, and links across a long conversation?

🎯

BEAM

Can it handle ten different memory skills such as ordering, updates, preferences, summaries, and contradictions?
